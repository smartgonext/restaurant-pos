# 🧪 CUSTOMER DISPLAY SYSTEM — SMOKE TEST GUIDE

## SETUP

### Prerequisites
- [ ] Both servers running: API on 3001, Web on 5174
- [ ] Two browser windows: **MainPOS** (http://localhost:5174/mainpos) and **Admin Dashboard** (http://localhost:5174/admin)
- [ ] Popup blocker disabled (or allow localhost popups)
- [ ] User logged in with POS permissions

---

## TEST 1: CREATE TOKEN & PRESENT TO CUSTOMER

### Step 1.1: Add Items to Cart (MainPOS)
1. Open http://localhost:5174/mainpos/terminal
2. Login with POS terminal credentials
3. Click on a **menu item** (e.g., "Biryani")
4. **Expected:** Item appears in cart on the right
5. Quantity: **1**
6. Add 2-3 more items
7. **Expected:** Cart updates with running total

### Step 1.2: Save as Token
1. Scroll down in the action panel (right side)
2. Click **"Save as Token"** button (purple)
3. **Expected:** 
   - Modal or confirmation appears
   - Token created (you may see a toast: "Token created")
   - Token number assigned (e.g., #125)
   - **"🖥️ Present to Customer"** button now visible

### Step 1.3: Present to Customer Display
1. Click **"🖥️ Present to Customer"** (green button)
2. **Expected:**
   - New window opens (size: 1920×1080)
   - Title: "Customer Display"
   - Should load bill automatically
3. **If popup blocked:** You'll see error toast "Failed to open customer display"
   - Fix: Add localhost exception in browser popup settings

### Step 1.4: Verify Bill Display
In the **Customer Display window**:
1. **Top Section (Left Side):**
   - Token Number (large) — e.g., "#125"
   - Item count (qty sum)
2. **Middle Section:**
   - Item list (name, qty, price each)
3. **Bottom Section:**
   - Subtotal
   - GST
   - **Total Amount** (large, bold)
4. **Button Panel:**
   - 🔵 "Show Payment QR"
   - 🟢 "Mark Paid (Cash)"
   - ⚫ "Reset"

**Expected:** All items match the MainPOS cart

## TEST 2: PAYMENT QR FLOW

### Step 2.1: Show Payment QR
1. In Customer Display, click **"Show Payment QR"** (blue button)
2. **Expected:**
   - Screen transitions to QR view
   - Large QR code displays (420×420)
   - Text: "Scan & Pay"
   - Two buttons: "Already Paid", "Back"

### Step 2.2: Verify QR Content (Optional)
1. Use phone camera to scan the QR
2. **Expected:**
   - Opens UPI pay link (GPay/PhonePe/Paytm app)
   - Merchant UPI pre-filled
   - Amount pre-filled (e.g., ₹500)
   - Token ID in transaction reference

### Step 2.3: Return from QR
1. Click **"Back"** button
2. **Expected:**
   - Screen transitions back to SHOWING state
   - Bill re-displays
   - Buttons visible again

## TEST 3: CASH PAYMENT

### Step 3.1: Mark as Paid
1. In Customer Display SHOWING state, click **"Mark Paid (Cash)"** (green button)
2. **Expected:**
   - Button becomes disabled
   - Toast appears: "Recording payment..."
   - Screen transitions (brief loading state)

### Step 3.2: Payment Success
1. **Expected:**
   - Screen shows: ✅ "Payment Confirmed"
   - Green success screen
   - Bill amount displayed
   - "Thank you & Visit Again!" message
2. **Timer:** Should display for **5 seconds**

### Step 3.3: Auto-Reset
1. After 5 seconds:
   - **Expected:**
     - Display clears
     - Returns to "Welcome!" IDLE state
     - Ready for next customer
     - Main POS should show "Paid Successfully"

## TEST 6: ERROR CASES

### Test 6.1: No Bill to Present
1. In MainPOS, clear all items (empty cart)
2. Click **"🖥️ Present to Customer"**
3. **Expected:** Toast error — "No bill to present"

### Test 6.2: Already Paid Token
1. In MainPOS, load a token that's marked "Paid"
2. Click **"🖥️ Present to Customer"**
3. Display shows: "Paid Successfully"
4. Try clicking **"Mark Paid"** again
5. **Expected:** Button disabled or error — "Token already paid"

### Test 6.3: Socket Down
1. In Customer Display, open Console
2. Check if socket is connected: `console.log(socket?.connected)`
3. If disconnected, fallback polling should still show latest order
4. **Expected:** Display continues to function (read-only)

## COMMON ISSUES & FIXES

| Issue | Cause | Fix |
|-------|-------|-----|
| Customer Display window doesn't open | Popup blocked | Allow popups for localhost in browser |
| Bill doesn't load in display | URL param not passed | Check URL: `/admin/customer-display?token=125` |
| "Unable to load bill details" | Server error | Check API logs, verify token exists |
| Socket events not received | Socket disconnected | Refresh display, check network |
| Payment doesn't record | API error | Check MainPOS permissions, server status |
| Display doesn't auto-reset | Timer issue | Refresh page, check browser console |
